# Security Policy

## Reporting

If you find a security issue, do not open a public GitHub issue with exploit details.

Report it privately to the maintainer first and include:

- impact
- affected area
- reproduction steps
- suggested fix if you have one

## Scope

Priority areas for this project:

- authentication
- online matchmaking
- Convex mutations and queries
- private room access
- environment and deployment configuration

## Disclosure

Please allow reasonable time for triage and a fix before public disclosure.
