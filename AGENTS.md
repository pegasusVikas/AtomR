# Project Notes

## Directory Conventions

- Store durable project docs, research notes, domain summaries, and reference material in `.docs/`.
- Store implementation plans, task breakdowns, and work-in-progress planning docs in `.plans/`.
- Prefer adding new documentation under `.docs/` instead of root-level markdown files when content is project-specific.
- Prefer adding new planning artifacts under `.plans/` instead of scattering plan files across repo.
